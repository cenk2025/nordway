# Demo images

Drop the hero gallery photos here as `hero-1.jpg` … `hero-6.jpg` (tall / portrait
orientation works best). Until a file exists, its panel shows a labelled
placeholder ("Demo image — replace (hero-N.jpg)").

Captions (name · role · year) are edited in `src/features/hero/hero-gallery.tsx`
(the `PANELS` array). Recommended size: ~1200×1600px, optimized JPG/WebP.
